自動監視ツール ガイド

⚡ 電力制度ウォッチャー

電力制度に関する最新情報を自動収集し、重要な情報はGmailでお知らせするツールです

このツールは何をするの？

電力制度に関する政府・機関のウェブサイトを毎日自動でチェックし、 前日から更新された情報があればGmailで通知します。
特に「一般送配電事業者がシステムを変更しなければならない可能性がある」記事は ⚠ 要注意フラグを付けて最上部に表示します。

処理の流れ（5ステップ）

🌐

① 情報を取得する

OCCTO・電力ガス取引監視等委員会・資源エネルギー庁などの公式サイトやニュースフィードにアクセスし、最新の記事一覧を取得します。

🔍

② 新着だけを抽出する

過去に送信した記事の URL を履歴ファイル（history.json）に記録しています。今回取得した中からまだ通知していないものだけを選び出します。

🤔

③ 重要度を判定する

記事のタイトルと本文に「系統連系」「需給調整市場」「省令改正」などの専門キーワードが含まれているか確認します。含まれていれば⚠ 要注意に分類します。

✉️

④ メールを送信する

新着記事がある場合のみ Gmail でメールを送信します。⚠ 要注意の記事はメール上部にまとめて表示されます。新着ゼロのときはメールは送られません。

💾

⑤ 履歴を保存する

今回通知した記事の URL を履歴に追加して保存します。次回実行時に重複して通知しないための仕組みです。

監視しているサイト

JSON API

OCCTO（広域的運営推進機関）

公式サイトのニュース一覧APIを直接取得。確実で高速な方法です。

Google News RSS

電力・ガス取引監視等委員会

Google ニュースで機関名を検索した結果をRSSで取得します。

Google News RSS

資源エネルギー庁

同様に Google ニュースから最新ニュースを取得します。

いつ動くの？

毎朝 6:00

GitHub Actions（クラウド上の無料自動実行環境）で毎日 JST 06:00 に自動実行されます。サーバーやPCをつけっぱなしにしておく必要はありません。

よくある疑問

メールが来ない日もあるの？

はい。監視サイトに新着情報がない場合はメールを送信しません。毎日必ず届くわけではありません。

同じ記事が何度も来ることはある？

ありません。一度通知した記事のURLは履歴ファイルに記録されるため、2回目以降は無視されます。

⚠ 要注意は絶対に見落とせない記事だけ？

キーワードの一致で判定しているため、関係のない記事が要注意になる場合（誤検知）もあります。あくまでも「目を通してほしい記事の候補」としてご活用ください。

複数人に送ることはできる？

できます。環境変数 GMAIL_TO にカンマ区切りでメールアドレスを並べると複数宛先に同時送信されます（例：a@example.com,b@example.com）。

監視するサイトを増やせる？

できます。config/sites.yaml にサイト情報を追記するだけで対応できます。HTML・RSS・JSON API の3種類の取得方式に対応しています。
